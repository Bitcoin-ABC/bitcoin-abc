# pay.e.cash

Universal eCash payment URLs use a BIP21 payload in the `bip21` query parameter:

`https://pay.e.cash?bip21=<bip21-uri>`

See the [BIP · eCash additions](https://github.com/Bitcoin-ABC/bitcoin-abc/blob/master/doc/standards/bip21-ecash-additions.md) spec for supported parameters.

If the wallet app is expected to return to the originating browser page after the payment, append `&b=1` to the link.

## Wallet connect links (Android Cashtab)

To connect a user's wallet address from your web app on Android:

`https://pay.e.cash/?connect=1&return_url=<https-url>&b=1`

Your page stays open while Cashtab opens. After approval, Cashtab opens `<return_url>#cashtab_connect=<ecash-address>` in the browser and exits. Parse the hash on load (see `parsePayEcashConnectCallback` in `cashtab-connect`).

## Agora action links

Agora action links open a token action in the user's wallet. They use the `/token` path:

`https://pay.e.cash/token?action=<LIST|BUY>&tokenId=<tokenId>`

See the [Agora action deep links](https://github.com/Bitcoin-ABC/bitcoin-abc/blob/master/doc/standards/agora-deeplink.md) spec for the full definition.

- `action` (required) — `LIST` to sell a token, `BUY` to buy one from an existing offer.
- `tokenId` (required) — the token the action applies to.
- `price` (optional, `LIST` only) — the list price in XEC.
- `quantity` (optional, `BUY` only) — the token quantity to buy, for fungible tokens.

Agora actions use their own path so that supporting them is optional for a wallet: a wallet can handle payment links at the root without handling `/token`.

The link may preselect an offer and prefill the form; it never submits or signs on its own. The wallet checks that the token exists, that it supports the action, and that the user can perform it, and the user confirms before anything is signed. For `BUY` the price always comes from the on-chain offer, never from the link.

## How to use pay.e.cash deep links in your App

You can programmatically generate intended txs for your users and encode them in a link. A user clicking the link will open the tx for their review and approval in Cashtab.
